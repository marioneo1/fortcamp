# Fortcamp Building Design (Tentative - not set in stone yet)

1. Max Population - Population count should be capped based on how many 'beds' there are. Tents provides two beds. We start with one tent. We'll be able to upgrade tent once to a big tent. Allowing four players. Player needs to discover blue print for a basic cabin and a sleeping bag. Blue print allows upgrade of big tent to basic cabin. Basic cabin can have furnitures and starts off with four sleeping bags. (Can be upgraded to a sleeping bed. Idk what bonus to do yet for the upgrade from sleeping bag to bed.) 
2. Prison Cell - Allows user to take in prisoners which they can later recruit. Needs a warden to be assigned to 'break' in the prisoners resistance for negotiation.
3. Personal Bounty Board - Missions distributed by user level, missions are not the same as the 'pool' missions. Rewards in this for early levels need to be worth a lot less compared to the POOL missions.
4. Kitchen - Assignable chefs/workers, each worker allows different recipes to be cooked more. Uses IRL world time. (Food can increase training EXP.)
5. Watchtower - Assignable guards. FOV dependent. Exposed, unmanned watchtower area without walls are dangerous areas. Things can be stolen?
6. Beast Kennel (Maybe better name?) - Assignable Keeper. Allows tamers or characters with beast slots to change their beast and level up their beasts. Keepers give beasts extra training EXP
7. Training Grounds - Assignable trainer. Passively increases all undeployed characters.
8. Stone Quarry, Lumber Mill, etc. This is to replace the manual quests where you lumber, mine, etc. Also note to self to delete almost all resource rewards from regular quests that doesn't reflect getting any of these.
9. Dining Hall - Food is set here. Food gives EXP multiplier buff to characters who eat.
10. Blacksmith - Assignable Smithy, Weapon and Armor refine. Also weapon crafting.
11. Scout Building - Assignable Scout. Scout level dictates scout range, scout will be given a selection of places to scout this will affect additional quest that goes into Personal Bounty Board.
